# Face-Recognizer-Facial-Recognition-Powered-Image-Retrieval
Face Recognizer is the process of finding personal photos from large event collections by using AI-based facial recognition while maintaining user privacy.

Face Recognizer is an artificial intelligence web application that uses facial recognition technology to help users quickly find their pictures in large event galleries. Users upload a selfie or take a picture of their face with a webcam, instead of scrolling through hundreds of pictures. The system picks up facial features and compares them with faces in the event gallery. It then displays only the photos that match. Other app features include secure user authentication, event management and photo uploads. This allows for faster, more accurate and privacy-aware retrieval of event photos.

Main Features
1. User authentication
2. Upload and Manage Event Photos
3. Search events by event name
4. Capture with webcam or selfie
5. Facial recognition powered by AI
6. Only show matched photos
7. Download matched images
8. Web UI that responds

Technologies Used
1. Frontend: HTML, CSS, JavaScript
2. Backend: Flask (Python)
3. Authentication: Firebase Authentication
4. AI: face-api.js with Tiny Face Detector, Face Landmark Detection, and Face Recognition models
5. Storage: Firebase Storage
